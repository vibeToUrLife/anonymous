# 宠物专属家具姿势 — 出图 Prompt

**Date:** 2026-08-07
**Status:** 素材规格 / 给 ChatGPT 出图用

## 这是什么

每只宠物解锁自己的专属家具（`decor_cat_throne` … `decor_jerry_mousehole`，见
`games/room/js/room-base.js:790`）之后，要有一格**配合那件家具的姿势**。

姿势格画的是**宠物本体**，家具是另一张独立的图（`games/room/img/furniture/decor_*.png`），
由程序分层叠起来。所以出图时**绝对不能把家具画进来**——画进来这格就废了。

## 图要长什么样（技术规格）

现有的每只宠物是**一张单列 sprite sheet，所有格等宽等高**：

| 宠物 | 现有格数 | 格子内容 |
|---|---|---|
| cat / dog / bunny / hamster / fox / panda / goose | 4 | 0=正面，1-2=侧面走，3=睡 |
| tom / jerry | 5 | 0=正面站，1-4=侧面走一圈 |

新姿势 = **在尾巴後面接一格**。所以生出来的图必须：

- **单只宠物、全身入镜**，耳朵尾巴四肢都不能裁到
- **脚（或身体最低点）踩在同一条地平线上** — 程式用 `FEET_Y = 0.38`（tom 0.52 /
  jerry 0.51）把每格对齐地板，格子之间地平线不一致的话，换姿势时脚会跳
- **身体大小和其他格一致** — 不能放大缩小，不然停下来的瞬间宠物会「长大」
  （jerry.js 的注解就吃过这个亏：参考图的转身列比走路列大 1.4 倍，打包前得缩回去）
- **背景纯透明**（或纯白好去背），脚下可以留现有那片淡椭圆影子
- 侧面姿势一律**朝右** — 房间把朝右当作未镜像方向，朝左是程式自己翻的

## 通用 Prompt（每次都贴这段，附上该宠物现有的 png 当参考图）

```
我要给一个卡通宠物游戏补画一格新姿势。附图是这只宠物现有的 sprite sheet，
里面已经有正面、走路、睡觉几格。请画出【同一只宠物】的新姿势格。

【最重要的规则 — 画面里只能有动物本身】
× 不要任何家具、道具、建筑、场景：王座、狗屋、花园、围栏、跑轮、洞穴、
  竹林、池塘、沙发、起司屋，一律不要
× 不要地板、草地、泥土、石头、植物、水面、波纹、光影特效
× 不要背景，背景必须纯透明（PNG）；做不到透明就用纯白 #FFFFFF
× 不要文字、标签、边框、格线、浮水印
× 只画一只动物，不要出现第二只
✓ 除了这只动物本身，画面上什么都没有

【风格 — 必须和附图完全一致】
- 同一只角色：一样的毛色、花纹、脸、眼睛、身体比例
- 一样的粗深色描边 + 扁平上色 + 柔和阴影的卡通风
- 一样的 Q 版比例（大头小身体）
- 不要变写实、不要变 3D、不要变像素风、不要改画风

【构图 — 要能直接拼进 sprite sheet】
- 全身入镜，耳朵、尾巴、四肢都不可以被裁到
- 动物置中，四周留一点空白
- 脚（或身体最低点）踩在画面底部的同一条地平线上，和附图其他格同高
- 身体大小和附图其他格一模一样，不要放大或缩小
- 画布正方形，1024×1024
- 脚下可以有一小片淡淡的椭圆影子，就和附图一样

【这一格的动作】
<<< 贴下面对应那只宠物的那一行 >>>

再提醒一次：只要动物本身，画面上不可以出现任何家具、场景、地面或背景。
```

## 实作注意

**一次只生一只。** 不要叫它一次生九只排成一张表 —— 每只的解析度会掉到没法用
（tom 的格子是 183×246，jerry 112×117，都是照原稿解析度打包的，缩过再放大就糊了），
而且一次要多只时它特别容易自己加场景把版面填满。

**它还是画了家具的话**，回这句就好，不用整段重贴：
> 重画：只要动物本身。删掉画面上所有家具、场景、地面和背景，背景改成纯透明。
> 动物的姿势、毛色、画风、大小全部保持不变。

**拿到图之后**：去背 → 缩到和该 sheet 其他格同高、地平线对齐 → 接到 sheet 尾巴 →
把对应 `*_CELLS` 加一，并在 `*_POSE_CELL` 加上新姿势的 key。

### 三条教训，补进 prompt

**一、角色一致性要点名，不能只说「和附图一致」。** 最大的失败都在这：tom 和 jerry
是**两足站立的拟人角色**，模型自动降级成四足小动物；bunny 的立耳被换成垂耳。
重生时要写死：

> tom 是两足站立、身体修长、四肢细的拟人卡通猫，不是四足小猫，头身比要和附图一样。
> jerry 是两足站立的拟人卡通老鼠，不是四足爬行的小鼠。
> bunny 是**立耳**（耳朵向上竖起），不是垂耳。

**二、要挡掉「抄睡觉格」。** dog 和 hamster 都退化成睡姿——参考图里就有一格睡觉，
模型会往最近的那格靠。重生时加一句：

> 这一格必须和附图里的睡觉格明显不同：眼睛张开、头抬起、是清醒有精神的姿势。

**三、一次生一只。** 八只挤一张，每只的指令遵循度都掉下来了——正面变侧面、
奔跑变趴平。解析度这次侥幸够（画布开到 1024×1536），但姿势的准确度赔进去了。

## 改版：家具姿势要 2 格，不是 1 格

宠物在自己家具旁边要有一点动作，所以每只不是补一格静态姿势，是补**一段 2 格循环**。

**为什么是 2 格。** 仓库里现成的走路循环就是 2 格（`cat.js` 的 `CAT_WALK_N = 2`，
tom/jerry 是 4），而且 `cat.js:25-30` 那段注解已经把理由写过了：这些画是慢悠悠地动，
两个拉得够开的姿势读起来就是在动，八个只会糊成一片抖动。补 2 格还有个好处——
播放机制完全沿用走路那套，用 leg phase 在两格之间挑，不用写新东西。

真的觉得某一只跳，那是**速率**的问题不是格数的问题：走路是 `*_STEP_RATE` 控的，
在家具旁边发呆本来就该慢，把速率调低就好。

**两格必须只差指定的那个部位。** 这是 2 格循环好不好看的全部关键——两格如果是
各画各的，循环起来就是在抽搐。所以 prompt 里写死「除了我指定的地方，其他完全一模一样」,
而且两格画在同一张图里一起生，比分两次生一致得多。

**接进去之后**：单排 strip 从 4 格变 6 格（tom/jerry 5 → 7），`*_CELLS` 跟着改，
再加一个 pose，像 walk 那样从 leg phase 在两格之间挑，而不是写死一格。

### 通用 prompt（每次贴这段，附上该宠物的 sheet，一次只生一只）

```
我要给一个卡通宠物游戏补画一小段循环动画。附图是这只宠物现有的 sprite sheet
（单排等宽格子：正面、走路、睡觉）。请用同一只宠物、同样画风，画出新的动作。

【张数 — 最重要的要求】
请在同一张图里画出【2 格】，左右并排，左边是第 1 格，右边是第 2 格。
这 2 格会不断循环播放，所以：
- 两格必须是同一只动物、同样大小、同一条地平线、同样的画风和颜色
- 两格之间【只有我指定的那个部位不一样】，其他部分要完全一模一样
- 不要画格线、边框、分隔线、编号、文字，两格之间留一点空白隔开就好

【画面里只能有动物本身】
```
